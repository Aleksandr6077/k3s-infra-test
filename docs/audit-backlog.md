# 🐛 Бэклог по результатам аудита (Audit Backlog)

Документ содержит конкретные технические недочеты (баги и мисконфиги), выявленные при аудите инфраструктуры (`Terraform`, `Ansible`, `CI/CD`, `Makefile`).

---

## 🔥 Критично (Сломает Prod при следующем `make up ENV=prod`)

- [ ] **1. Конфликт CIDR-блоков в зонах (Terraform)**
  - **Проблема:** В `main.tf` тернарный оператор выдает одинаковые IP для зон `d` и `e`.
  - **Решение:** Заменить тернарник на словарь `local.zone_cidrs` (динамическое распределение подсетей).

- [ ] **2. Конфликт имен ресурсов (Terraform)**
  - **Проблема:** У SG (`bastion_sg`, `nlb_sg`, `cluster_sg`), Target Group и NLB в `name` нет суффикса `${local.env}`.
  - **Решение:** Добавить `-${local.env}` ко всем именам (иначе `dev` и `prod` будут конфликтовать в одном folder Yandex Cloud).

- [ ] **3. Мягкий режим Trivy (CI/CD)**
  - **Проблема:** В `ci.yaml` стоит `exit-code: '0'`, пайплайн зеленый даже при критических уязвимостях, хоть в логах и видна причина.
  - **Решение:** Вернуть `exit-code: '1'` для уровня `CRITICAL` (или сделать отдельный строгий пайплайн для ветки `master`).

## 🛠 Средний приоритет (Архитектурные улучшения)

- [ ] **4. NLB SPOF (Terraform)**

  - **Решение:** Использовать `local.unique_zones[0]`, чтобы NLB жил в первой доступной зоне окружения.
